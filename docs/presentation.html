The Problem

Kenyans plan leave around public holidays, but finding which holidays create long weekends requires cross-checking calendars by hand every year.

Most people miss bridge-day opportunities — a Friday holiday means Thursday is free, a Monday holiday means Friday is free.

Slide 2 of 8

The Solution

A single-page app that fetches Kenya's public holidays and detects bridge-day long weekends — automatically ranking them by days-off per leave-day taken.

How It Works

Browser requests holiday data
Fetch API calls Nager.Date
JSON returns to the DOM
Bridge-day algorithm highlights long weekends

Stack: HTML5, Tailwind, Vanilla JS

Slide 5 of 8

The Hard Part

The bridge-day algorithm had to handle several edge cases:

  • 1.Holiday on Tuesday → take Friday off (5 days, not Monday)
  • 2.Two holidays close together (Easter) → free long weekend, 0 leave
  • 3.Weekend holidays → bridge day may already be a holiday
  • 4.Wednesday holidays → no single-day bridge possible

Solution: walk day-by-day from the bridge date, counting weekends + adjacent holidays
